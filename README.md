## 🪐 Overview & Premise

As the Commander of Mars Expedition Base Alpha, you are responsible for the survival and expansion of a fragile pioneer outpost on the Martian regolith. 

Every second corresponds to **1 simulation tick** (1,000 ticks = 1 Sol). Time advances continuously, even when operators are offline, through an authoritative catch-up engine that applies batch state transitions with mathematical determinism.

---

## ⚙️ Core Gameplay Mechanics

### Life Support Thermodynamics
* **Oxygen (O2)**: Consumed by living colonists at **3 O2/tick** each. Produced by **Oxygen Scrubbers** (+5 O2/tick). Each operational scrubber additionally expands the colony's maximum oxygen buffer capacity by **+5 O2** beyond the 100 base.
* **Power (PWR)**: Generated by **Solar Arrays** (+5 PWR/tick) and consumed by all active facilities. If power drops to 0, electrical heating collapses, causing colonists to suffer hypothermia damage.
* **Food (FOOD)**: Consumed by living colonists at **3 Food/tick** each. Produced by **Hydroponic Farms** (+5 Food/tick). 
* **The Life Support Check**: If **Oxygen == 0**, **Power == 0**, or **Food == 0** at the end of a tick while net demand exceeds production, all colonists take **-2 HP damage/tick**. Once health reaches 0, the colonist perishes.

### Workforce & Colonist Labor
* **Labor Capacity**: Each living colonist supports up to **4 operational facilities** ($\text{Max Operational Buildings} = \text{Colonists} \times 4$). Habitats are residential and exempt from this limit.
* **Aging & Lifespan**: Colonists have unique lifespans seeded between 6,000 and 10,000 ticks (6–10 Sols).
* **Automated & Direct Maintenance**: Idle colonists automatically travel to repair broken structures (provided electronics are available) or dig out buried buildings. Operators can also dispatch maintenance crews directly from the **Building Inspector**.

### Surface Mining & Refining Economy
* **Subterranean Ore**: 500 units of raw ore are seeded across 15–25 terrain tiles at colony generation.
* **Balanced Extraction**: **Extractors** mine local tile deposits at **1 Ore per 5 ticks** for only **1 PWR draw/tick**, delivering sustainable resource income without overwhelming the power grid.
* **Ore Refineries**: Transform 10 raw Ore into rechargeable **Battery Cells** (100% initial efficiency) required for rover dispatch. Battery cells in storage experience slow degradation (-1 efficiency/tick).

### Autonomous Rover Logistics
* **Rover Garages**: House up to 2 autonomous exploration rovers.
* **Mining Expeditions**: Dispatches a fueled rover to rich, distant Martian surface mining sites (60–120 Ore).
* **Asteroid Interceptions**: Temporary meteoric impacts spawn high-value resource deposits with fixed lifetime countdowns.
* **Recovery Protocol**: If a rover runs out of power mid-transit, an idle colonist walks to its coordinates to tow it back to base.

### Supply Transports & Escort Protocols
* Every **300 ticks**, an interplanetary supply transport lands at Landing Pad **(0, 0)** carrying **1 new Colonist** and **2 Electronics**.
* **150-Tick Escort Window**: A rover must be dispatched from a Garage to meet the transport before the countdown expires; otherwise, the lander departs and its cargo is lost.
* **Emergency Kit**: Every colony starts with **2 Electronics** and mechanical breakage is suppressed until **tick 500**, ensuring commanders can build a Garage and safely escort their first arrival.

### Environmental Hazards & Weather
* **Dust Storms**: Beginning Sol 2.5 (tick 2,500), periodic Martian dust storms have a 30% chance to bury up to 2 structures in regolith, requiring 40 ticks of colonist excavation.
* **Mechanical Wear**: After tick 500, facilities have a 1-in-4,000 chance per tick of mechanical breakdown, requiring replacement electronics and engineering labor.

## 🖥️ UI & Control Systems

### Intelligent Mission Advisor HUD
Positioned prominently at the top-center of the screen, the **Mission Advisor** analyzes live telemetry every tick and presents prioritized, dismissible tactical guidance:
* **Critical Alerts**: Power grid brownouts, oxygen starvation warnings, colonist health degradation.
* **Logistics Prompts**: Transport ship touchdown alerts with rover dispatch reminders.
* **Progression Advice**: Extractor site selection, battery cell refining, and agricultural expansion guidance.

### Contextual Building Inspector
Clicking any structure or the Landing Pad opens its dedicated Inspector card:
* **Status & Telemetry**: Condition (`OPERATIONAL`, `STANDBY`, `BROKEN`, `BURIED`), power draw/yield, neighbor overcrowding efficiency, and local deposit reserves.
* **Direct Facility Controls**:
  - `[ ⚡ TURN OFF / RESTORE POWER ]`: Shed power load instantly to protect critical life support.
  - `[ ✥ RELOCATE STRUCTURE (10 PWR) ]`: Move operational facilities to new tiles.
  - `[ 💥 DEMOLISH STRUCTURE (10 PWR) ]`: Demolish structures to reclaim space (preserves underground ore).
  - `[ 🔧 DISPATCH REPAIR ]` & `[ ⛏ DISPATCH EXCAVATION ]`: Route maintenance crews immediately.
  - `[ 🚀 DISPATCH ROVER ESCORT ]` & `[ ⛏ DISPATCH MINING EXPEDITION ]`: Control garage rovers directly.

### Subterranean Ore Highlighting
Selecting the **Extractor tool** dynamically illuminates all subterranean ore deposits with glowing cyan diamonds and `◆ ORE` indicators, enabling optimal placement without revealing exact unmined quantities.

### Interactive Landing Beacon
When an arrival touches down at `(0, 0)`, an interactive overhead HUD beacon renders directly on the game canvas (`[ 🚀 DISPATCH ESCORT ]`), enabling one-click escort dispatches.

## 🏗️ Technical Architecture

### Deterministic Simulation Tick Engine
* **Pure Mathematical Transitions**: Given state $S_t$ and seed $\sigma$, $S_{t+1} = \text{tick}(S_t, \sigma)$. Applying $N$ ticks in a single batch produces the exact same outcome as applying $N$ individual ticks.
* **Seeded PRNG**: All stochastic events (storm timing, breakage targets, ore placement, lifespans) use a custom Linear Congruential Generator / Mulberry32 PRNG stored in colony state, completely avoiding `Math.random()`.

### Isometric Mathematics & Render Pipeline
* **Coordinate Transforms**: Strict 2:1 isometric projection transforms screen $(x, y) \leftrightarrow \text{grid}(u, v)$.
* **Back-to-Front Depth Sorting**: Structures, colonists, and rovers are sorted dynamically by depth key $(x + y) \times 1000 + z$ to guarantee correct occlusion and visual volume hit-testing.

### Authoritative Server & Database Design
* **Database Isolation**: Tables (`marscolony_colonies`, `marscolony_buildings`, `marscolony_colonists`, `marscolony_rovers`, `marscolony_battery_cells`) enforce Row-Level Security (RLS).
* **Monotonic Tick Invariant**: Client-side projection never rewinds or decrements ticks during server synchronization.

## 🛠️ Getting Started

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher
* **Supabase CLI** (optional for local edge function testing): `v2.0.0+`

### Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/JacintoDesign/ZTM-Mars-Colony.git
   cd ztm-mars-colony
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```

4. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

5. **Build for production**:
   ```bash
   npm run build
   ```

### Edge Function Deployment

To deploy updated simulation functions to Supabase:
```bash
npx supabase functions deploy tick
npx supabase functions deploy action
```
